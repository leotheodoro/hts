# 0027 · Round de Luta na progressão

Data: 2026-10-28 · Status: aceita (decisão do Leo, #42)

## Decisão
- Cada round completo de um bloco Round de Luta conta como uma série concluída: +10 XP e alimenta os atributos do bloco.
- O volume soma kg × rounds de cada exercício do round.
- Rounds não contam para Limite Quebrado: a carga do round não é uma marca medida série a série.

`progressHistory` (TS) e `Progression.history` (Swift) recebem os rounds de cada sessão e rodam o mesmo fixture.
